📄 Modelos de Documentos

Repositório de modelos utilizados pelo DEPLAN/CPG para padronização das atividades.

📧 Modelo de E-mail

Solicito a relotação dos usuários constantes na planilha anexa, favor mantê-los vinculados a apenas uma unidade.

➕ Modelo de Cadastro

Solicito o cadastramento dos usuários constantes na planilha anexa. Caso já exista cadastro ativo, favor desconsiderar o pleito e informar a ocorrência.

❌ Modelo de Remoção

Solicito a remoção dos usuários das subunidades conforme planilha anexa.

✏️ Modelo de Alteração

Solicito a alteração dos dados dos usuários conforme planilha anexada.

✅ Encerramento de Chamado

Desconsidere os usuários com pendências e prossiga com o procedimento para os demais usuários. Após a conclusão das tratativas, solicito o encerramento do chamado.

📑 Informação para Processo

Modelo para elaboração de informação em processo administrativo e tramitações SEI.
